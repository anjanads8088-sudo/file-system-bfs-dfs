# File System Representation and Search Using BFS and DFS

## Description
C program to represent a file system as a graph using an adjacency matrix and search files using Breadth-First Search (BFS) and Depth-First Search (DFS).

## Features
- Graph representation using an adjacency matrix
- BFS traversal and file search
- DFS traversal and file search
- Displays traversal order and search results

## Programming Language
C

## How to Run
1. Compile using: `gcc main.c -o main`
2. Run using: `./main`
3. Enter the number of nodes, adjacency matrix, starting node, and target node.
